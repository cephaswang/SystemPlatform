    **** 功能介紹： Ad Hoc Expressions（即時自訂表達式）是 AVEVA Historian Web Client 的一項功能，允許使用者使用製程標籤（Process Tags）與函數，直接在瀏覽器中建立自訂表達式並產生新數值。

    **** 建立儀表板： 範例中首先建立一個簡單的儀表板，選用兩個資料標籤：紐澤西總流量（Total flow for New Jersey）與紐約總流量（Total flow for New York），設定查看過去一小時的資料並轉為堆疊折線圖（Stacked Line Chart）。

    **** 新增自訂表達式： 點擊資料按鈕中的「Add Expressions」新增表達式。首先建立兩個標籤的總和（Summarization）表達式；輸入時系統會根據關鍵字自動建議支援的函數與標籤。

    **** 各種算術與統計表達式範例：

        計算紐澤西流量占總流量的百分比。

        計算兩地流量相減後的絕對值（Absolute Value）。

        重命名表達式並編輯其參數。

        新增過去 15 分鐘內紐約流量的平均值（Average）。

        新增過去 15 分鐘內紐約流量的最大值（Max Value）。

    **** 圖表互動與單位處理： 在圖表上懸停游標可即時查看對應時間點的數值。預定義的維度數學計算機制，讓不同工程單位的標籤能輕鬆混合使用於表達式中。

    **** 邏輯函數表達式應用： 示範使用 IF 邏輯函數，當紐澤西流量大於 56 時傳回值 1。點擊項目旁色彩標籤可隱藏特定數據，方便比對高值與原始資料。

    **** 持續時間計算與總結： 計算紐澤西流量超過 56 的持續時間（Duration）。AVEVA Historian Web Client 的 Ad Hoc Expressions 互動式編輯器，讓使用者只需透過瀏覽器就能隨選分析數據。
